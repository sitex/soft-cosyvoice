# Цель

Репозиторий **CosyVoice** — вендоренный клон upstream-проекта FunAudioLLM/CosyVoice (https://github.com/FunAudioLLM/CosyVoice). Проект представляет собой систему синтеза речи (TTS) на основе больших языковых моделей с поддержкой многоязычия (9+ языков, 18+ китайских диалектов), zero-shot голосового клонирования и потоковой генерации аудио с низкой задержкой (от 150 мс). Предназначен для исследования и интеграции передовых алгоритмов TTS в собственные приложения.

## Критерии готовности

- [ ] Модель Fun-CosyVoice 3.0 (0.5B параметров) загружена и инициализирована
- [ ] Базовый inference-скрипт работает (синтез речи из текста, вывод в WAV)
- [ ] Поддерживается многоязычный синтез (минимум русский/английский/китайский)
- [ ] Реализована поддержка потокового вывода (streaming mode)

## Политика ответов

- Водитель сам решает: обновления моделей, экспериментальные параметры inference, локальные утилиты для тестирования TTS.
- Эскалировать человеку: изменение зависимостей (requirements.txt, torch/CUDA версии), деплой инструментов, смена архитектуры обработки потока данных, интеграция в production-системы.

## Ограничения

- **Платформа**: Linux/MacOS/Windows; GPU-поддержка требует CUDA 12.1+ на Linux, onnxruntime-gpu на Linux.
- **Язык**: Python 3.10+; модели обучены и оптимизированы для многоязычного TTS.
- **Зависимости**: тяжелые (torch 2.3.1, transformers 4.51, tensorrt-cu12, deepspeed); требует ≥ 30 ГБ дискового пространства для моделей.
- **Статус**: upstream-репо, не управляется sitex; коммиты отражают развитие проекта FunAudioLLM, локальные изменения ограничены скриптами интеграции.
